## Background: Codex Seraphinianus

The Codex Seraphinianus (Luigi Serafini, 1981) is an illustrated encyclopedia of an imaginary world, written in an undeciphered script. Its high-entropy glyph system (~50 minuscules with parametric loops, ~412 majuscules) serves as a stress-test for our cross-domain pipeline, validating robustness under maximum symbolic entropy.

## Background: Ripley Scroll

The Ripley Scroll (Sir George Ripley, 15th century) is a 6-7 meter illuminated manuscript depicting alchemical dissolution stages for the philosopher's stone. The alkahest (universal solvent) dissolves metals to prima materia. We map these stages to signal processing:

2. **Dragon**: Universal dissolve → Fourier energy projection (prima materia)
