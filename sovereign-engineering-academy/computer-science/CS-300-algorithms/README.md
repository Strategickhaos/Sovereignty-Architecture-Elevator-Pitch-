# CS-300: Data Structures and Algorithms

## Course Description

Analysis and design of algorithms and data structures. Focus on complexity analysis, sorting/searching algorithms, graph algorithms, and optimization techniques.

## Learning Objectives

By the end of this module, you will:
- Analyze algorithm complexity using Big O notation
- Implement fundamental data structures from scratch
- Design and optimize sorting and searching algorithms
- Apply graph algorithms to real-world problems
- Understand dynamic programming and greedy approaches
- Recognize NP-complete problems

## Module Structure

### Lessons
- 01: Big O Notation and Complexity Analysis
- 02: Sorting Algorithms (Bubble, Merge, Quick, Heap)
- 03: Search Algorithms (Binary, DFS, BFS)
- 04: Graph Algorithms (Dijkstra, A*, Floyd-Warshall)
- 05: Dynamic Programming (Memoization, Tabulation)
- 06: Greedy Algorithms
- 07: Divide and Conquer
- 08: NP-Completeness

### Implementations
All algorithms implemented in:
- Python (readable, beginner-friendly)
- Rust (performance, memory safety)
- JavaScript (web applications)
- FlameLang (novel language, TRIG6 integration)

### Projects
1. Sorting Algorithm Visualizer
2. Pathfinding for TRIG6 pipe routing
3. Optimization solver for PDE systems

### Real-World Applications
- TRIG6 pipe routing optimization
- PDE solver algorithm selection
- Infrastructure planning algorithms
