## Overview

This repository contains both **narrative synthesis** and **audit-grade documentation** for the DOM Operating System project.

These serve different purposes and should be read with different expectations.

| Document | Purpose | Truth Standard | Audience |

## Reading Guidelines

### For DOM_OS_THEATER.md (Narrative)

This document:
- Expresses subjective experience and metaphor
- Uses theatrical framing for emotional truth
- Contains interpretive synthesis by AI systems
- Is NOT intended as peer-reviewed academic writing

**Read it as:** A memoir. A synthesis. A meaning-making document.

**Do NOT read it as:** A legal deposition. A scientific paper. An audit report.

### For DOM_OS_EVIDENCE.md (Audit)

This document:
- Classifies every major claim
- Distinguishes verified, self-reported, and interpretive content
- Acknowledges limitations and suggests verification methods
- Provides conversation sources where available

**Read it as:** An evidence index. A fact-check companion. A trust document.

---

## Claim Classification System

| Tag | Meaning |
|-----|---------|
| `[VERIFIED]` | Artifacts exist and can be independently checked |
| `[SELF-REPORT]` | Subject's account of personal experience |
| `[INTERPRETATION]` | Pattern synthesis by AI or analyst |
| `[METAPHOR]` | Figurative language, not literal claim |
| `[UNCITED]` | Claim made without available source |

---

## Why Both Documents Exist

Human experience is complex. Some truths are:
- **Measurable** (code exists, files have timestamps)
- **Testimonial** (I experienced this, witnesses confirm)
- **Interpretive** (this pattern means something)
- **Metaphorical** (this is like that)

Collapsing all of these into one frame loses information.

The theatrical document preserves **meaning**.
The evidence document preserves **verifiability**.

Both are needed for complete understanding.

---

## Source of Truth Hierarchy

When in doubt:

```
1. Code and artifacts (compiler decides)
2. Timestamps and logs (machines don't lie)
3. Evidence document (classified claims)
4. Narrative document (meaning-making layer)
```

## For Critics and Skeptics

If you're reading this with skepticism, good. That's healthy.

Here's what we ask:
1. Read the EVIDENCE document for classified claims
2. Note what is verified vs. self-reported vs. interpretive
3. Check the suggested verification methods if you want to confirm
4. Understand that narrative documents serve a different purpose than audits

We're not asking you to believe everything.
We're asking you to understand what category each claim falls into.
