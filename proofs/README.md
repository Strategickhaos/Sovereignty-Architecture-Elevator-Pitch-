## How to Generate Proof

### Prerequisites

1. PostgreSQL client (`psql`) installed
2. Neon database credentials
3. Bash shell

### Step 1: Set Database URL

```bash
export NEON_DATABASE_URL='postgresql://user:password@host.neon.tech/strategickhaos-core'
```

### Step 2: Run Verification Script

```bash
cd scripts
./verify_neon_database.sh
```

### Step 3: Review Results

```bash
cd ../proofs/neon_verification
ls -lh  # View generated files
```
