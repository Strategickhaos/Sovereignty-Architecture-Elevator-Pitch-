## Overview

FlameLang IR is a frozen intermediate representation for the FlameLang compiler. All compiler passes must consume and produce this exact structure.

## Architecture

The IR consists of several key sections:

### Section A: IR Data Model (Frozen Node Kinds)
- **FlameIR enum**: The complete set of IR node kinds
  - Module, FnDef, Block, Let, Const, Call, Return, Extern, Var, BinOp
- **Type System**: Minimal type system supporting Int, Float, Bool, String, Unit, and Function types

### Section B: Pass Interface
- **TransformPass**: IR → IR transformations (pure, no side effects)
- **ValidatePass**: IR → Diagnostics (no mutation)

### Section C: Invariants (Hard Rules)
Three critical invariants that must always hold:
1. Every Return statement occurs inside a FnDef
2. All Call targets are resolvable to FnDef or Extern
3. Every Let binding is unique within its scope

### Section D: Pass Stubs
- **PassTRIG6Lowering**: Convert high-level codec ops to runtime calls (stub)
- **PassTRIG6Validate**: Validate TRIG6-specific constraints (stub)

### Section E: Builder Helpers
Convenience functions for constructing IR nodes programmatically

### Section F: Examples & Tests
- hello.flame IR example (the "birth certificate")
- Invariant violation tests

## Example Usage

```rust
use flamelang::{builder::*, FlameType, InvariantChecker};

// Build a simple program
let ir = module("hello", vec![
    extern_fn("print", vec![FlameType::String], FlameType::Unit),
    fn_def("main", vec![], FlameType::Unit,
        block(vec![
            call("print", vec![const_string("Hello, FlameLang!")]),
            ret(None),
        ])
    ),
]);

// Validate invariants
let diagnostics = InvariantChecker::check_all(&ir);
assert!(diagnostics.is_empty());
```
