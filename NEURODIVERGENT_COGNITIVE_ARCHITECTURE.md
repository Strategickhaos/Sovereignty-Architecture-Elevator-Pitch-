## 🎯 Design Principles for Neurodivergent-Friendly Systems

When building tools for minds like this:

### ✅ DO:
- Expose the underlying logic
- Make everything scriptable
- Support parallel workflows
- Enable deep inspection
- Provide symbolic representations
- Allow infinite composition
- Make state visible and queryable

### ❌ DON'T:
- Hide implementation details
- Force linear workflows
- Require GUI navigation
- Use opaque abstractions
- Lock users into specific paths
- Prevent inspection
- Separate interface from logic
