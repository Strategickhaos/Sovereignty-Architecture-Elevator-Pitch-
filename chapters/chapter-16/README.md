## 🔬 TRIG6 Framework

### Fitness Function
```
f = R * (1-D) * (1-N) * e^(-α)
```

Where:
- **R**: Resource efficiency (0-1)
- **D**: Drift (process degradation, 0-1)
- **N**: Noise (environmental variability, 0-1)
- **α**: Alpha (damping/intervention, 0-1)
- **θ**: Theta (phase angle complexity, 0 to π/2)

### Fitness Thresholds
- **f ≥ 0.70**: Exceptional (500+ year lifespan)
- **f ≥ 0.55**: Archival quality (100+ years)
- **f ≥ 0.44**: Durable (50+ years)
- **f ≥ 0.33**: Functional (10+ years)
- **f < 0.25**: Unstable (failure likely)

## 🔧 Potentiometer Proof Engine

### Concept
A **kinesthetic analog-to-phase transducer** that converts subjective material science processes into quantitative fitness metrics.

### How It Works
1. **User turns potentiometer dial** → simulates process variable (temperature, humidity, tension, etc.)
2. **Arduino reads position + noise** → sends to computer via serial
3. **Python computes TRIG6 fitness** → f = R(1-D)(1-N)e^(-α)
4. **Display shows real-time status** → Green (stable), Yellow (marginal), Red (unstable)

### Revolutionary Impact
- **First time** process validation has been made kinesthetically interactive
- **Converts** "cook until translucent" → "f ≥ 0.55 for stable adhesive"
- **Democratizes** 4,000 years of material science knowledge
