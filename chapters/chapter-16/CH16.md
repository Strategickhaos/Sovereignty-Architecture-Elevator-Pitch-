## 1. Classic Reed Papyrus (Egyptian Standard)

### Archaeological Description
The foundation of Western literacy. *Cyperus papyrus* reeds from the Nile Delta, harvested at peak cellulose content, cross-layered to create the world's first true writing substrate.

### Reconstruction Steps
1. **Harvest**: Cut papyrus reeds 15-20cm from base (highest cellulose density)
2. **Strip**: Remove outer green rind, expose white pith
3. **Soak**: Submerge strips in Nile water (or lime-water) for 6-8 days
4. **Arrange**: Cross-layer strips horizontally and vertically
5. **Mallet**: Pound to compress fibers and express cellular sap
6. **Press**: Apply weight (stone blocks) for 24-48 hours
7. **Sun Dry**: Slow desiccation under controlled heat
8. **Polish**: Smooth surface with shell or bone tool

### Chemical Substrate
- **Primary Component**: Cellulose (C₆H₁₀O₅)ₙ — 60-70%
- **Secondary Component**: Hemicellulose — 15-25%
- **Lignin**: <5% (minimal, crucial for flexibility)
- **Natural Adhesive**: Cellular sap polysaccharides

```

### Danger Zones
**None.** This is one of the safest ancient processes. All materials are natural, non-toxic, and biodegradable.

## 2. Lime-Infused Papyrus (Pharaoh Grade)

### Archaeological Description
The premium variant used for sacred texts and royal decrees. Soaking papyrus in lime water (calcium hydroxide) increases whiteness, stiffness, and archival longevity.

### Reconstruction Steps
1-2. (Same as Classic Papyrus: harvest and strip)
3. **Lime Soak**: Soak in Ca(OH)₂ solution (pH 12-13) for 8-10 days
4. **Rinse**: Thorough washing to remove excess alkali
5-8. (Continue as Classic Papyrus: arrange, mallet, press, dry, polish)

### Chemical Substrate
- **Cellulose**: 60-70% (same base)
- **Calcium Hydroxide**: Ca(OH)₂ ions embedded in fiber matrix
- **Effect**: OH⁻ ions break down lignin, increase whiteness
- **Byproduct**: Calcium carbonate (CaCO₃) coating

### TRIG6 Signature
```
θ = π/4        (45° phase - higher complexity)

```

**Fitness**: f ≈ 0.52

### Danger Zones
**Moderate.** Lime is caustic (pH 12-13).
- Wear gloves to prevent skin burns
- Avoid eye contact
- Ensure thorough rinsing before handling

### Potentiometer Proof Path

## 13. Coptic Sew (Standard Chain Stitch)

### Archaeological Description
The oldest intact codex binding. Developed in Egypt (2nd-4th century CE), this is the foundation of Western book structure. Chain stitch links signatures directly to wooden boards without adhesive.

### Signature Geometry
- **Fold**: Sheets folded in half (folio) or quarters (quarto)
- **Gathering**: Multiple folded sheets nested (4-8 sheets typical)
- **Sewing Stations**: 3-5 holes punched along spine fold

### Stitch Topology
```
Station 1 ----\
               \
Station 2 ------*------ Chain Link
               /
Station 3 ----/
```

1. **Entry**: Needle enters first signature from inside
2. **Exit**: Exits to board attachment point
3. **Chain**: Links to previous signature via loop
4. **Repeat**: Continue linking signatures sequentially

### Load-Bearing R Values
```
Spine Tension: R = 0.75 (moderate strength)
Board Attachment: R = 0.68 (weakest point)
Thread Durability: R = 0.82 (linen is excellent)

### 4.4.2 — Mapping Rules

The potentiometer position maps to TRIG6 parameters:

#### Secondary Mapping: N (Noise/Variability)

voltage = analogRead(A0) * (5.0 / 1023.0);

**Interpretation:**
- Potentiometer **position** → Primary variable (e.g., temperature)

D = rate_of_change(θ);  // dθ/dt

**Interpretation:**
