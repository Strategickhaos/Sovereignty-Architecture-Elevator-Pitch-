## EEG Band → TRIG6 Parameter Mapping

Standard EEG frequency bands map to TRIG6 angle θ:

| EEG Band | Frequency Range | TRIG6 θ Range | Clinical State |
|----------|----------------|---------------|----------------|
| Delta (δ) | 0.5-4 Hz | 0°-30° | Deep sleep, unconscious |
| Theta (θ) | 4-8 Hz | 30°-60° | Drowsy, meditative |
| Alpha (α) | 8-13 Hz | 60°-120° | Relaxed, eyes closed |
| Beta (β) | 13-30 Hz | 120°-210° | Alert, focused |
| Gamma (γ) | 30-100 Hz | 210°-360° | Peak cognition, processing |

Neurological diseases often show **anomalous patterns** in these bands:
- Alzheimer's: Reduced alpha, increased delta/theta
- Epilepsy: Sudden gamma spikes, theta dysregulation
- Parkinson's: Beta band oscillations, alpha slowing

By mapping these patterns to θ, we derive six TRIG6 metrics:
1. **sin(θ)** — Vertical waveform component
2. **cos(θ)** — Horizontal waveform component
3. **tan(θ)** — Slope / rate of change
4. **Resonance** — Energy stability
5. **Drift** — Deviation from baseline
6. **Danger Zone** — Proximity to failure states

## Computational Framework

### TRIG6 Projection for Each Disease

For disease D with primary EEG signature at frequency f Hz:
1. Convert f to θ using calibration curve (e.g., 10 Hz → 90°)
2. Compute 6 metrics:
   - sin(θ) = vertical component
   - cos(θ) = horizontal component
   - tan(θ) = slope
   - Resonance = 1 - |drift|
   - Drift = (θ_current - θ_baseline) / θ_baseline
   - Danger = 1 if |tan(θ)| > threshold else 0

3. Map to FlameLang WAVE layer for simulation
4. Feed to Darwinian compiler for hypothesis evolution
