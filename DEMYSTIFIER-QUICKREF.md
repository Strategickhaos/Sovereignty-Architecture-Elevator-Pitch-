## Grounding Checks

1. ✓ **MEASURABLE** - Can you assign a number?
2. ✓ **FALSIFIABLE** - What would prove it wrong?
3. ✓ **BOUNDED** - Where does it start/end?
4. ✓ **OBSERVABLE** - Can someone else verify?
5. ✓ **ACTIONABLE** - What do you DO?
6. ✓ **OWNABLE** - Who is responsible?
