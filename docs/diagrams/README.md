# Technical Diagrams

This directory contains technical diagrams and visual documentation for the Strategickhaos DAO LLC project.

## Diagrams

### Mechanical Advantage Systems

**File:** `mechanical_advantage_systems.svg`

A comprehensive technical diagram illustrating rope mechanical advantage systems used in professional rope access and rescue operations. This diagram is part of the TRIG6 Rope Mechanics training materials, aligned with SPRAT (Society of Professional Rope Access Technicians) Level 3 certification standards.

**Contents:**
- 1:1 Redirect System (direction change only)
- 2:1 System (simple mechanical advantage)
- 3:1 Z-Rig (classic rescue system)
- 4:1 System (compound mechanical advantage)
- Key formulas for calculating theoretical and actual mechanical advantage
- Pulley efficiency calculations
- Force and tension relationships

**Usage:**
This diagram can be viewed directly in web browsers or included in documentation using:

```markdown
![Mechanical Advantage Systems](diagrams/mechanical_advantage_systems.svg)
```

Or as an HTML image:

```html
<img src="diagrams/mechanical_advantage_systems.svg" alt="Mechanical Advantage Systems" />
```

**Technical Standards:**
- Society of Professional Rope Access Technicians (SPRAT) Level 3
- NFPA 1983 - Standard on Life Safety Rope and Equipment for Emergency Services
- ASTM standards for rope rescue equipment

**Applications:**
- Professional rope access operations
- Technical rescue training and operations
- Industrial height safety
- Emergency services and mountain rescue
