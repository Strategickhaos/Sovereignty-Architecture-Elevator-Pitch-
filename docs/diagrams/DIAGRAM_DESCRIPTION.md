# Mechanical Advantage Systems Diagram - Visual Description

## Overview
This SVG diagram (800x600px) illustrates four rope mechanical advantage systems used in professional rope access and rescue operations.

## Visual Layout

The diagram is divided into four main sections, arranged horizontally:

### Section 1: 1:1 Redirect (Left)
- **Visual**: Single pulley at anchor point
- **Rope path**: Straight down, over pulley, back down
- **Load**: Red box labeled "W" 
- **Pull force**: Arrow showing "W" (equal to load)
- **Key insight**: "Direction change only" - no mechanical advantage
- **Anchor load**: 2W (sum of both rope strands)

### Section 2: 2:1 System (Center-Left)
- **Visual**: One fixed pulley at anchor, one traveling pulley attached to load
- **Rope path**: Two strands supporting the load
- **Load**: Red box labeled "W"
- **Pull force**: W/2 (half the load weight)
- **Key insight**: "2 strands support load"
- **Formula**: Pull = W ÷ 2

### Section 3: 3:1 Z-Rig (Center-Right)
- **Visual**: Three pulleys arranged in Z-pattern
  - Top pulley: Fixed at anchor
  - Middle pulley: Traveling (movable)
  - Bottom pulley: Attached to load
- **Rope path**: Creates characteristic "Z" shape
- **Load**: Red box labeled "W"
- **Pull force**: W/3 (one-third the load weight)
- **Key insight**: "Classic rescue system"
- **Formula**: Pull = W ÷ 3

### Section 4: 4:1 System (Right)
- **Visual**: Four pulleys (2 at anchor, 2 at load)
- **Rope path**: Four strands supporting the load
- **Load**: Red box labeled "W"
- **Pull force**: W/4 (one-quarter the load weight)
- **Key insight**: "4 strands support load"
- **Formula**: Pull = W ÷ 4

## Key Formulas Section (Bottom)
A highlighted blue box containing essential calculations:

1. **Theoretical MA** = Number of strands supporting the load
2. **Actual MA** = Theoretical MA × (Pulley Efficiency)^(number of pulleys)
3. **Pull Force** = Load ÷ MA
4. **Rope Travel** = Load Travel × MA

### Example Calculation
- 3:1 system with 2 pulleys at 90% efficiency
- Actual MA = 3 × 0.9 × 0.9 = 2.43
