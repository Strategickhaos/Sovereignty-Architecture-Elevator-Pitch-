# FlameLang Periodic Table of Invariants

A visual representation of the FlameLang symbolic language's 64 core elements organized by transformation type and domain.

## Viewing the Periodic Table

Open `flamelang-periodic-table.html` in any modern web browser to view the interactive periodic table.

### Features

- **64 Elements** organized across 5 transformation types:
  - STATE: Base state elements
  - TRANSFORM: Transformation operations
  - INVARIANT: Invariant properties
  - WAVE: Periodic/temporal operations
  - COLLAPSE: Resolution operations

- **9 Domains** with distinct color schemes:
  - Core (purple)
  - Egyptian (pink)
  - Babylonian (cyan)
  - Alchemical (green)
  - Transistor (orange)
  - Physics (blue)
  - DNA (pastel)
  - Music (pink gradients)
  - Fabrication (peach)

- **Interactive Tooltips**: Hover over any element to see:
  - Full name
  - Atomic number
  - IR type
  - Computational mass (Big-O notation)

- **Educational Sections**:
  - Bonding Rules showing transformation operations
  - Named Reactions from historical algorithms
  - 64-State Attractor demonstrating convergence
  - Hebrew Alphabet Elements mapping
