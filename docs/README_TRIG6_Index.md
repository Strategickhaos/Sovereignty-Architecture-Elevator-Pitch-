## 🔑 Key Concepts

### The Four-Stage Architecture

```
[Potentiometer] → [ADC Sampling] → [TRIG6 Engine] → [Evolution Gate] → [Proven Config]
      ↓                ↓                  ↓                 ↓                ↓
  Physical         Converts to        Computes R,D,N    Validates       Logs proven
  Uncertainty      Phase Space        θ, fitness        Stability       Basins
```

### TRIG6 State Variables

- **R (Resonance)** — Self-reinforcement strength
- **D (Drift)** — Deviation tendency from equilibrium
- **N (Noise)** — Stochastic perturbations
- **θ (Phase)** — Angular position in cycle (0 to 2π)
- **f (Fitness)** — Success/stability measure (0 to 1)

### Evolution Equations

```
θ = (pot_value / ADC_max) * 2π
R = R_prev + α·cos(θ) + N
D = |θ - θ_prev| + decay·D_prev
f = fitness_function(R, D, θ, N)
```

### Proof Criterion

A configuration is **proven** when:
- Fitness f ≥ threshold (typically 0.8-0.95)
- No danger conditions detected
- State remains stable for minimum duration

## 🚀 Quick Start

### Hardware Requirements (Minimal)

- Arduino Uno (or equivalent microcontroller)
- 10kΩ linear potentiometer
- 3× LEDs (green, red, yellow)
- Breadboard and jumper wires
- **Total cost: ~$38**

### Software Setup

1. Clone this repository
2. Install Arduino IDE
3. Load TRIG6 firmware (see examples directory)
4. Upload a `.t6` configuration file
5. Connect hardware according to pin assignments
6. Turn the potentiometer and observe LED feedback

### Your First Proven Configuration

1. Upload `basic_potentiometer.t6` config
2. Connect pot to A0, LEDs to D2/D3/D4
3. Slowly turn potentiometer
4. Green LED = proven configuration found!
5. Check serial output for validated parameters
