## 🛡️ Guardian Layer (ORB1)

AI safety system using a 4-oracle ensemble:

1. **SignatureOracle** - Pattern matching (Snort/Yara-style)
   - Detects confidence without evidence
   - Identifies fabricated citations
   - Catches temporal inconsistencies

2. **EntropyOracle** - Shannon information theory
   - Calculates text entropy
   - Detects anomalous patterns
   - Measures information density

3. **NetworkOracle** - Behavioral analysis
   - Analyzes structural patterns
   - Detects templated content
   - Monitors logical consistency

4. **SearchSpaceOracle** - Complexity analysis
   - Measures vocabulary richness
   - Calculates combinatorial complexity
   - Evaluates search space size

**Ensemble Scoring:** Weighted combination of all oracles
- 0-25: LOW (Minor concerns)
- 25-50: MEDIUM (Review recommended)
- 50-75: HIGH (Significant warnings)
- 75-100: CRITICAL (Reject content)
