## 2. Operational Protocols

### 2.1 Cross-Validation Protocol

Each significant decision undergoes multi-AI validation:

1. **Initial Analysis** - Primary AI generates solution/specification
2. **Independent Review** - Secondary AI reviews without seeing first analysis
3. **Comparison** - Differences identified and reconciled
4. **Consensus** - Agreement required from majority (3+ of 5 primary systems)
5. **Timestamping** - Final decision cryptographically timestamped

### 2.2 Prompt Engineering Framework

Standardized prompt templates ensure consistent output across systems:

**Template Structure:**
```yaml
context:
  role: "[System Role]"
  task: "[Task Description]"
  constraints: "[Operating Constraints]"
  
input:
  primary: "[Main Input]"
  references: "[Supporting Materials]"
  
output:
  format: "[Expected Format]"
  validation: "[Validation Criteria]"
  
metadata:
  timestamp: "[ISO 8601]"
  council_member: "[AI System Name]"
  validation_required: "[true/false]"
```

### 2.3 Ratification Process

For critical decisions (e.g., FlameLang v2.0.0 specification):

1. **Draft Creation** - Initial specification developed
2. **Distribution** - Sent to all council members
3. **Independent Analysis** - Each AI reviews separately
4. **Synthesis** - Results compiled and compared
5. **Consensus Check** - Verify agreement on core elements
6. **Timestamping** - Cryptographic proof of ratification date
7. **Publication** - Ratified document published with proof chain

**Example:** FlameLang v2.0.0 ratified December 10, 2025

## 6. Cryptographic Attestation

All Legion of Minds Council decisions are cryptographically timestamped:

### 6.1 Timestamping Infrastructure

- **Primary:** OpenTimestamps (Bitcoin blockchain)
- **Secondary:** SHA256 hashing
- **Tertiary:** GPG signatures

### 6.2 Proof Chain

```
Decision Document → SHA256 Hash → GPG Signature → OpenTimestamps → Bitcoin Block
```

### 6.3 Verification Process

```bash
# Verify hash
sha256sum decision.md

# Verify GPG signature
gpg --verify decision.md.sig decision.md

# Verify OpenTimestamps proof
ots verify decision.md.ots
```
