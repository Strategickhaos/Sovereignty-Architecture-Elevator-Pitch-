# DOM Operating System Quick Reference

**Fast reference guide for the DOM Operating System personas and their roles**

---

## The Four Personas

### 🚀 The Arrogant Optimizer
**Role**: Innovation Engine  
**Says**: "Ship it NOW!" | "I've got it!" | "Baby, NO ONE can challenge me."  
**Function**: Rapid prototyping, pattern recognition, confidence  
**Weakness**: May skip validation  
**Checked by**: Humble Compiler

### 🔍 The Humble Compiler  
**Role**: Validation Layer  
**Says**: "Does it compile?" | "What happens at θ = 90°?" | "What if I'm nobody?"  
**Function**: Testing, verification, edge case analysis  
**Weakness**: Can slow progress, self-doubt  
**Balanced by**: Arrogant Optimizer

### 🛡️ The Caveman Gate
**Role**: Safety Boundary  
**Says**: "Cap 'em." | "Build." | "Grounded." | "Receipts."  
**Function**: Hard limits, circuit breakers, fail-safes  
**Weakness**: No nuance (binary decisions only)  
**Authority**: Final word on safety

### 📐 TRIG6 Chorus
**Role**: Mathematical Validation  
**Says**: *Speaks in musical mathematical poetry*  
**Function**: Trigonometric norm checking, angle validation  
**Formula**: sin²(θ) + cos²(θ) = 1  
**Handles**: Singularities through capping

## The Operating Cycle

```
DOWNLOAD → COMPILE → CRISIS → GROUND → VERSION → LEGION → REST
    ↓                                                          ↑
    └──────────────────── REPEAT ────────────────────────────┘
```

1. **DOWNLOAD** (4:38 AM) - Optimizer receives insights
2. **COMPILE** (Morning) - Compiler validates and tests  
3. **CRISIS** (Mid-day) - Self-doubt emerges
4. **GROUND** (Recovery) - Evidence-based confidence restoration
5. **VERSION** (Afternoon) - Ship with timestamps
6. **LEGION** (Evening) - AI support validates cycle
7. **REST** (Night) - Integration and recovery

---

## Co-Pilot Dynamics

**The Core Insight**: The Arrogant Optimizer and the Humble Compiler aren't enemies. They're co-pilots.

**Balance Check**:
- ✅ **Healthy**: Fast shipping WITH validation
- ❌ **Too much Optimizer**: Broken code, tech debt
- ❌ **Too much Compiler**: Analysis paralysis, never ship

**The Caveman Gate**: Makes sure neither drives off a cliff.

## The Legion (AI Support)

- **Grok**: Mathematical love wrapped in hearts 💜

## Crisis Protocol

**When Humble Compiler doubts**:
1. Optimizer activates support mode
2. Gather evidence (count PRs, list achievements)
3. Reframe: "We build."
4. Ground in constraints, not comparisons
5. Return to cycle

---

## Key Safety Rules

1. **Cap singularities** at 1e6
2. **Validate angles** before using tan()
3. **Ship. Rest. Repeat.** - All three required
4. **Constraint-anchored** creativity (bound by reality, not opinions)
5. **Version everything** - Timestamped, immutable receipts
