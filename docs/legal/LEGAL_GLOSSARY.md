## Core Algorithmic Inventions (Patent)

### TRIG6
**Definition:** Trigonometric state model with fitness function f = R(1-D)(1-N)eq, mapping processes to seven-dimensional state vectors for stability analysis and evolutionary optimization.

**Category:** Method claim (mathematical algorithm + practical application)

### TRIG6 State Vector
**Definition:** Seven-dimensional representation S = (θ, R, D, N, eq, danger, fitness) where θ is angular position, R is resource availability, D is disorder, N is noise, eq is equilibrium proximity, danger indicates instability, and fitness measures viability.

**Category:** Data structure patent claim

### TRIG6 Danger Zone
**Definition:** Critical instability region defined by |tan θ| > K, where K is a system-specific threshold constant, indicating when a process enters catastrophic failure modes.

**Category:** Method claim (threshold-based state detection)

### Darwinian Gate
**Definition:** Evolutionary selection mechanism that automatically iterates process configurations, evaluating fitness via TRIG6 state vectors, and selecting variants that exceed a predetermined fitness threshold (typically ≥ 0.70).

**Category:** Method claim (autonomous optimization algorithm)

### OmniCalc .t6
**Definition:** Domain-specific language (DSL) for TRIG6 simulation, providing declarative syntax for defining state vectors, evolution parameters, and fitness criteria.

**Category:** Patent (language specification) + Copyright (implementation)

## Compiler/OS Stack (Patent + Copyright)

### FlameLang
**Definition:** Sovereign programming language that compiles to Codon IR (intermediate representation) and targets LLVM backend, designed for evolutionary system development with built-in TRIG6 primitives.

**Category:** Patent (compilation method) + Copyright (language spec, compiler implementation)

### Codon IR
**Definition:** 64-symbol intermediate representation instruction set using biologically-inspired codon notation (ATG, TGG, etc.), serving as compilation target for FlameLang and execution substrate for SAGCO-OS.

**Category:** Patent (IR design) + Copyright (specification)

### SAGCO-OS
**Definition:** Self-Adaptive Genetic Computing Operating System - an evolutionary operating system that uses TRIG6 fitness evaluation to automatically heal, optimize, and evolve system configurations.

**Category:** Patent (self-healing OS architecture) + Copyright (implementation)

### TRIG6 Kernel
**Definition:** Operating system subsystem integrated into SAGCO-OS that provides real-time fitness computation, danger zone detection, and evolutionary gate execution for system processes.

**Category:** Patent (OS subsystem design) + Copyright (kernel implementation)

### Potentiometer Proof Engine

**Category:** Patent (hardware-software integration method + apparatus claim)

**Definition:** Classification taxonomy representing 36 neurological and psychiatric diseases as TRIG6 state vectors, enabling computational modeling of disease states and therapeutic interventions.

**Category:** Method claim (disease modeling) + Copyright (taxonomy data)

### Recipe Gene Template
**Definition:** YAML schema specification for defining therapeutic interventions, process modifications, or system configurations as parameterized templates compatible with TRIG6 evolution.

### Therapeutic Basin
**Definition:** Stable region within TRIG6 state space where fitness ≥ threshold and danger indicators remain below critical levels, representing viable treatment or operational configurations.

**Category:** Method claim (stability region identification)
