## Key Concepts

### TRIG6 Framework
- **θ (Theta)**: Phase of failure (0 to 2π radians)
- **R (Resonance)**: Mitigation strength (0 to 1)
- **D (Drift)**: Deviation from optimal (0 to 1)
- **N (Noise)**: Uncertainty/entropy (0 to 1)
- **Danger Zone**: tan(θ) > 10 indicates critical threshold

### Fitness Function
```
f = R × (1 - D) × (1 - N) × eq
```
Where eq is equation/code quality [0, 1]
