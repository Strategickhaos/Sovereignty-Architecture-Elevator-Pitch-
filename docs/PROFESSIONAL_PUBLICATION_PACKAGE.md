## 10. FREQUENTLY ASKED QUESTIONS

### What is Dramatic Systems Archaeology?
DSA is a methodology that applies archaeological principles to software systems. 
It treats code and configuration as artifacts that can be systematically discovered, 
documented, and verified, rather than simply declared or asserted.

### How is this different from existing verification methodologies?
Traditional verification often starts with assertions about what a system should do. 
DSA starts with discovery of what artifacts actually exist and what they actually do. 
Intent is measured through analysis, not declared through specification.

### What is the SAGCO Boot Identity Pipeline?
SBIP applies DSA principles to system boot, establishing identity and provenance from 
initialization. It displays verifiable identity information rather than making 
unsupported claims.

### Is this methodology practical for real-world development?
Yes. The project demonstrates 67 pull requests completed in a single focused session, 
all with full documentation and verification. The methodology enables rather than 
hinders velocity.
