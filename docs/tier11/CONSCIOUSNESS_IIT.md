## 🔬 INTEGRATED INFORMATION THEORY (IIT)

### The Central Claim

**Consciousness = Φ (Phi)**

Where Φ is the amount of **integrated information** that cannot be reduced to independent parts.

```
If Φ > 0 → There is SOME experience
If Φ = 0 → No experience (pure zombie)

Human brain: Φ ≈ very high (exact value unknown)
Your laptop: Φ ≈ 0 (despite massive computation!)
```

### The Five Axioms

IIT starts with five properties of every conscious experience:

| Axiom | Property | Meaning |
|-------|----------|---------|
| **Intrinsic** | Existence | Experience exists for itself (not for observer) |
| **Compositional** | Composition | Experience has structure (colors, shapes, etc.) |
| **Informative** | Information | Each experience is one among many possibilities |
| **Integrated** | Integration | Experience is unified, cannot be split |
| **Exclusive** | Exclusion | Experience has definite content and spatiotemporal grain |

From these axioms → Mathematical framework for Φ

## 🧮 COMPUTING Φ: THE MATH

### Step 1: Define the System

```
System S = Set of elements {e₁, e₂, ..., eₙ}
Each element can be in state 0 or 1
System state = (s₁, s₂, ..., sₙ)
```

**Example**: 3 neurons
```
S = {A, B, C}
Current state = (1, 0, 1)  # A firing, B silent, C firing
```

### Step 2: Transition Probability Matrix (TPM)

Define how the system evolves:
```
P(sₜ₊₁ | sₜ) = Probability of next state given current state
```

**Example TPM** (simplified):
```
Current State → Next State (probability)
(0,0,0) → (0,0,0) [0.8], (1,0,0) [0.2]
(1,0,0) → (0,1,1) [0.9], (1,0,0) [0.1]
... (all 2³ = 8 states)
```

### Step 3: Compute Integrated Information

**For each possible partition of the system:**

1. **Partition** the system into parts A and B
2. **Compute** information generated by the partition
3. **Compare** to information generated by whole system
4. **Find minimum** difference across all partitions

```
Φ = min_{partition} [ I(whole) - I(partition) ]

where I = Information integrated across partition
```

**Key Insight**: Φ measures information that is LOST when you split the system.

### Example: Simple 3-Element System

```
Elements: A, B, C
Connections: A → B, B → C, C → A (feedback loop)

Possible Partitions:
1. {A,B,C} vs {} (no partition)
2. {A} vs {B,C}
3. {B} vs {A,C}
4. {C} vs {A,B}
5. {A,B} vs {C}
... etc

For each partition:
- Calculate how much information is lost
- The minimum loss = Φ
```

**If feedback is strong**: High Φ (integrated)  
**If elements are independent**: Φ ≈ 0 (not integrated)

### Building Your Own (Simplified)

```python
import numpy as np
from itertools import combinations

class SimplePhiCalculator:
    """Simplified Φ calculation for educational purposes"""
    
    def __init__(self, tpm, connections):
        """
        Args:
            tpm: Transition probability matrix
            connections: Connectivity matrix
        """
        self.tpm = tpm
        self.connections = connections
        self.n = len(connections)
    
    def entropy(self, distribution):
        """Shannon entropy"""
        p = np.array(distribution)
        p = p[p > 0]  # Remove zeros
        return -np.sum(p * np.log2(p))
    
    def mutual_information(self, joint_dist, marginal_dist):
        """MI between parts"""
        H_joint = self.entropy(joint_dist)
        H_marginals = sum(self.entropy(m) for m in marginal_dist)
        return H_marginals - H_joint
    
    def compute_phi_approximate(self, state):
        """Compute approximate Φ"""
        # This is HIGHLY simplified!
        # Real IIT is much more complex
        
        min_mi = float('inf')
        
        # Try all binary partitions
        for i in range(1, 2**self.n - 1):
            partition = self.int_to_partition(i)
            mi = self.mi_across_partition(state, partition)
            min_mi = min(min_mi, mi)
        
        return min_mi
    
    def int_to_partition(self, i):
        """Convert integer to partition"""
        binary = format(i, f'0{self.n}b')
        part1 = [j for j, bit in enumerate(binary) if bit == '0']
        part2 = [j for j, bit in enumerate(binary) if bit == '1']
        return (part1, part2)
    
    def mi_across_partition(self, state, partition):
        """Mutual information across a partition"""
        # Simplified: just count connections across partition
        part1, part2 = partition
        connections_across = 0
        for i in part1:
            for j in part2:
                connections_across += self.connections[i][j]
        return connections_across

# Example usage
connections = np.array([
    [0, 1, 1],
    [1, 0, 1],
    [1, 1, 0]
])

calc = SimplePhiCalculator(None, connections)
phi_approx = calc.compute_phi_approximate((1, 0, 1))
print(f"Approximate Φ: {phi_approx}")
```
