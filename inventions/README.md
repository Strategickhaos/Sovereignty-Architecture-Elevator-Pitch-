## Structure

Each invention is assigned a unique identifier (INV-XXX) and maintains:
- Complete technical documentation
- Classification (convergent, novel, or hybrid)
- Publication information
- Licensing terms
- Version history

```
inventions/
├── README.md (this file)
└── INV-XXX/
    ├── [MAIN_DOCUMENT].md
    ├── INVENTION_REGISTRY.md

```

## Classification System

Inventions are classified as:

### CONVERGENT
- Applies existing, well-established knowledge
- No novel technical contribution
- May represent useful compilation or organization
- Example: Standard rope knot guide

### NOVEL
- Introduces new concepts, methods, or technologies
- Original technical contribution
- Potentially patentable (if pursued)
- Example: New mechanical device or algorithm

### HYBRID
- Combines existing knowledge in novel ways
- New application or framework for established principles
- Unique pedagogical or practical approach
- Example: TRIG6 system (existing math, novel application)

## Contributing

### Adding a New Invention

1. **Request INV-XXX identifier** from repository maintainers
2. **Create directory structure**:
   ```bash
   mkdir -p inventions/INV-XXX
   mkdir -p inventions/INV-XXX/appendices
   ```
3. **Document thoroughly**:
   - Main technical content
   - INVENTION_REGISTRY.md file
   - Classification and rationale
   - Licensing terms
4. **Submit for review**:
   - Pull request with complete documentation
   - Technical review by qualified experts
   - Legal review for IP considerations

### Updating Existing Inventions

- Follow version control practices
- Document changes in version history
- Major revisions may increment INV identifier
- Maintain backward compatibility when possible
