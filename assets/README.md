# SAGCO OS Assets Directory

This directory contains assets for the SAGCO OS boot identity and branding.

## Files

### banner.ascii
ASCII art representation of the "Ratio Ex Nihilo" emblem - displayed in boot banner.

### ratio_ex_nihilo.png
**PLACEHOLDER**: Add your emblem image here.

The "Ratio Ex Nihilo" emblem should be placed in this directory as `ratio_ex_nihilo.png`.
This image will be used for:
- Plymouth boot splash screen
- Desktop wallpaper
- System branding

**Expected specifications:**
- Format: PNG
- Recommended size: 512x512 or larger
- Transparent background recommended for overlay use

The emblem features the circular sigil with lightning/tech overlays from the original design.
