# T-Mobile Business Credit Application Helper

A React web application that provides quick access to T-Mobile business credit information for Strategickhaos DAO LLC, featuring one-click copy-to-clipboard functionality for all important details.

## Features

- **Quick Copy**: One-click copy-to-clipboard for all contact numbers and business information
- **Visual Feedback**: Instant confirmation when items are copied
- **Call Script**: Pre-formatted script ready to use when calling T-Mobile
- **Application Checklist**: Track the status of application requirements
- **Responsive Design**: Works on desktop and mobile devices

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Technology Stack

- **React 18** - UI framework
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Styling and design system
- **Clipboard API** - Native browser copy functionality

## Usage

Visit the application and click on any field to copy its contents to your clipboard. The interface includes:

- **Credit Review Team**: 1-877-323-5617 (for verification & eligibility)
- **Business Care**: 1-877-347-2127 (general inquiries)
- **Business Details**: EIN, legal name, state filing, representative info
- **Call Script**: Ready-to-use phone script with all necessary information

## Building

The production build generates optimized static files in the `dist/` directory that can be deployed to any web server or static hosting service.
