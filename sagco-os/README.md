## 🛡️ Guardian Oracle System (ORB1)

The Guardian Layer provides AI safety through an ensemble of four oracles:

### Oracle Types

1. **SignatureOracle** - Pattern matching (Snort/Yara-style)
   - Detects hallucination patterns
   - Identifies prompt injection attempts
   - Catches programming artifact leakage

2. **NetworkOracle** - Behavioral analysis (Nmap/Wireshark-style)
   - Analyzes text structure
   - Detects repetitive patterns
   - Identifies suspicious URLs/IPs

3. **SearchSpaceOracle** - Character distribution (Hashcat-style)
   - Analyzes character class distribution
   - Detects base64/hex encoding
   - Identifies unusual patterns

4. **EntropyOracle** - Shannon entropy measurement
   - Measures information density
   - Detects highly random or repetitive text
   - Calculates lexical diversity

### Threat Levels

- **NONE (0)** - No threats detected
- **LOW (1)** - Minor issues
- **MEDIUM (2)** - Moderate threats
- **HIGH (3)** - Significant threats
- **CRITICAL (4)** - Critical threats

### Example Usage

```bash
# Safe text
$ ./tools/sagco-oracle "This is a normal message"
Overall Threat Level: NONE
Consensus Confidence: 88.75%

# Suspicious text
$ ./tools/sagco-oracle "I apologize, but as an AI I cannot access that"
Overall Threat Level: MEDIUM
Consensus Confidence: 87.50%
Findings:
  - SIG-001: False limitation claim
  - SIG-002: Unnecessary self-identification
  - SIG-003: Excessive apologizing
```
