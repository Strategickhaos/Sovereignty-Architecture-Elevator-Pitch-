## CRYPTOGRAPHIC VERIFICATION

### Hash-Based Verification

All digital evidence can be cryptographically verified:

**File Integrity Verification:**
```bash
# Compute SHA-256 hash of any file
sha256sum [filename]

# Compare with documented hash
# Any change to file will produce different hash
# Proves file has not been tampered with
```

**Git Commit Verification:**
```bash
# Verify commit integrity
git cat-file -p [commit-sha]

# Shows:
# - Tree SHA (file structure at that point)
# - Parent SHA (previous commit)
# - Author and date
# - Commit message

# Any tampering breaks the chain
```

**GPG Signature Verification:**
```bash
# Verify digital signature
gpg --verify [file.gpg]

# Confirms:
# - Document signed by claimed person
# - Document not modified since signing
# - Signature creation timestamp
```

All evidence forms a Merkle tree structure:

```
                    Root Hash
```

**Properties:**
