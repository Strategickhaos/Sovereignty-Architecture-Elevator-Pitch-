## Usage

### Quick Start: Protect a New Innovation

```bash
# Basic usage
cd /path/to/repository
./scripts/ip_protection.sh \
  --innovation "Your Innovation Name" \
  --description "Detailed description of what you invented"

# With specific files and Git tag
./scripts/ip_protection.sh \
  --innovation "New Algorithm" \
  --description "Revolutionary approach to X" \
  --files "algorithm.py,docs/spec.md" \
  --create-tag

# Full automation
./scripts/ip_protection.sh \
  -i "Multi-Agent System" \
  -d "Distributed AI coordination protocol" \
  -f "src/coordinator.py,docs/architecture.md" \
  -c "system" \
  -p "github,academic,ai" \
  --auto-commit --gpg-sign --create-tag
```

### What Happens

1. **Creates IP Record:** Markdown file with complete documentation
2. **Generates Metadata:** JSON file with structured information
3. **Computes Hashes:** SHA-256 hashes for verification
4. **Commits to Git:** Timestamped commit with your innovation
5. **Optional Tag:** Creates Git tag for easy reference
6. **Multi-Platform:** Records prepared for GitHub, academic, AI platforms

## Legal Framework

### Applicable Laws

- **35 U.S.C. § 102:** Prior art provisions (US Patent Law)
- **Article 54 EPC:** Novelty requirements (European Patent Convention)
- **Federal Rules of Evidence:** Authentication and admissibility standards

### Effect of Public Disclosure

Once publicly disclosed via GitHub:
1. Creates prior art under patent law
2. Defeats novelty of future patent applications by others
3. Preserves inventor's right to file (US grace period: 12 months)
4. Enables freedom to operate

### Rights Preserved

- ✅ Original inventor can still file patents (within grace periods)
- ✅ Can practice inventions freely
- ✅ Can license or commercialize
- ✅ Can enforce against unauthorized use
