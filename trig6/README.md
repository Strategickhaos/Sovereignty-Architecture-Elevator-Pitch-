# TRIG6: Trigonometry for Rope Access and Rescue

## Overview

TRIG6 is a comprehensive technical manual that unifies trigonometry concepts for rope access and rescue technicians. This book fills a critical gap in the field by:

- Unifying trig into a single framework (TRIG6)
- Explicitly teaching why mechanical advantage and angles behave as they do
- Integrating physical tools (PCS-1, cards, stencils)
- Speaking directly in a technician's voice

## Educational Framework

### TRIG6 Core Concepts
1. **Mechanical Advantage** - Force multiplication in rope systems
2. **Angle Geometry** - Load distribution in anchors and rigging
3. **Dynamic Forces** - Impact loading and fall factors
4. **Secant Amplification** - Tension multipliers in deviation systems
5. **System Integration** - Multi-anchor redundancy and safety factors
6. **Field Patterns** - Practical decision-making frameworks

### Field Pattern Format
```
FIELD PATTERN — [Short Name]
What it is
What it does
What to do about it
```
