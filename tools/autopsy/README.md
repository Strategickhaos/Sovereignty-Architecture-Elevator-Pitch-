# Binary Autopsy - Third-Party Deconstruction

## Purpose
Deconstruct third-party binaries, strip "shady vibes", reassemble into clean flame::tool.

## Autopsy Process

1. **Disassemble**: Convert binary to assembly
2. **Analyze**: Identify suspicious patterns
3. **Strip**: Remove telemetry, tracking, unnecessary code
4. **Sanitize**: Replace unsafe operations with safe equivalents
5. **Rebuild**: Compile into flame::tool
6. **Verify**: Test behavior matches original (minus shady parts)

Ensures third-party tools are sovereignty-compliant.
