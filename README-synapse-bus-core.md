## Architecture

The synapse-bus-core follows a bio-mimetic architecture with the following major components:

### Core Systems
- **Nervous System** (`src/nervous_system/`): Spike, Dendrite, Reflex primitives
- **Primitives** (`src/primitives/`): Membrane, Nucleus, Error handling
- **Homeostasis** (`src/homeostasis/`): Gradient, Dissolve mechanisms
- **Claims** (`src/claims/`): GSCH Claim 8, INV-088 Holo bindings
- **Council** (`src/council/`): Legion ratification, Synthesis engine
- **Immune System** (`src/immune_system/`): Red, Blue, Purple teams
- **Organs** (`src/organs/`): Vision, Speech, Touch interfaces
- **Infrastructure** (`src/infra/`): Nodes, Autopilot, Spot gambler
- **UI** (`src/ui/`): Holodeck, Narrative layers
