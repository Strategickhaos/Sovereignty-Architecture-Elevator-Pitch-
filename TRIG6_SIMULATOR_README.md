## TRIG6 Framework

The TRIG6 framework evaluates alchemical processes using four key parameters:

- **θ (theta)**: Phase angle mapped from process progress s ∈ [0,1]
- **R (resonance)**: Computed from ingredient balance and progress
- **D (drift)**: Based on amount extremity and hazard level
- **N (noise)**: Era-dependent uncertainty estimation

### Fitness Function

```
f = R × (1 - D) × (1 - N) × eq
```

Where:
- R = Resonance (0 to 1)
- D = Drift (0 to 1)
- N = Noise (0 to 1)
- eq = Equilibrium constant (~0.9)

### Danger Zone

A process enters the danger zone when:
```
|tan(θ)| > 10
```

This typically occurs when the phase angle approaches π/2 or 3π/2 (quarter-turn points).

## Usage

### Basic Usage

Run the simulator with default recipes:

```bash
python3 trig6_pharmacopeia_simulator.py
```

This will:
1. Simulate 5 alchemical recipes
2. Run 1,000 Monte Carlo iterations per recipe
3. Generate a detailed report with statistics
4. Save the report as `trig6_simulation_report_YYYYMMDD_HHMMSS.md`

### Output

The simulator outputs:
- Real-time progress for each recipe
- Mean fitness and danger rate statistics
- A comprehensive markdown report including:
  - Executive summary with aggregate statistics
  - Individual recipe results
  - Methodology description
  - Cryptographic proof (SHA-256 hash)

## Architecture

### Classes

- **`TRIG6Framework`**: Core mathematical computations
  - `compute_theta()`: Phase angle calculation
  - `compute_resonance()`: Ingredient balance resonance
  - `compute_drift()`: Process drift from extremity
  - `compute_noise()`: Era-dependent uncertainty
  - `is_danger_zone()`: Danger threshold check
  - `compute_fitness()`: Overall fitness function

- **`PharmacoopeiaSimulator`**: Monte Carlo simulation engine
  - `simulate_recipe()`: Run full simulation for a recipe
  - `_simulate_run()`: Single simulation iteration

- **`ReportGenerator`**: Report formatting and generation
  - `generate_report()`: Create comprehensive markdown report

- **`Recipe`**: Recipe data structure
  - name, code, hazard_level, ingredients

- **`RecipeStats`**: Aggregated simulation results
  - mean_fitness, std_fitness, danger_rate, best_config

## Simulation Parameters

- **Steps per run**: 100 (granularity of process simulation)
- **Monte Carlo runs**: 1,000 per recipe (configurable)
- **Random seed**: System time (for reproducibility, can be set)
