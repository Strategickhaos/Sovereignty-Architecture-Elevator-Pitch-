## 🔥 EXECUTIVE SUMMARY

The TRIG6 Projection Curve Stencil (PCS) represents a novel physical drafting tool that bridges mathematical precision with practical fabrication needs. Unlike traditional French curves which use arbitrary, artist-derived shapes, the PCS uses parametric trigonometric generation to create mathematically exact curves for pipe fabrication and general drafting applications.

**Key Innovation:** Physical embodiment of the TRIG6 projection framework in a multi-angle stencil with integrated angular indexing and software generation pipeline.

## 📝 PATENT CLAIM STRUCTURE (Draft)

### CLAIM 1: Physical Stencil
A curve stencil comprising:
  (a) an angular index rail marked in degrees from 0° to 360°;
  (b) a plurality of projection curves, each curve defined by the 
      formula h(θ) = r × tan(α) × cos(θ) where α is a branch angle;
  (c) segment index markers corresponding to discrete angular positions;
  (d) extrema indicators marking high, low, and centerline positions.

### CLAIM 2: Multi-Angle Configuration
The stencil of Claim 1, wherein the projection curves include curves for branch angles of 30°, 45°, and 60°.

### CLAIM 3: Generation Method
A method for generating a projection curve stencil comprising:
  (a) receiving a pipe diameter and branch angle as inputs;
  (b) computing discrete points using trigonometric projection;
  (c) interpolating a smooth curve through said points;
  (d) outputting a vector file suitable for manufacture.

### CLAIM 4: Software System
A computer-implemented system for the method of Claim 3.

## 🏗️ TECHNICAL SPECIFICATION

### Mathematical Foundation
```
h(θ) = r × tan(α) × cos(θ)

Where:
  h(θ) = height of projection at angle θ
  r = pipe radius
  α = branch angle (30°, 45°, 60°, etc.)
  θ = angular position (0° to 360°)
```

### Physical Features
1. **Angular Index Rail**: Degree markings from 0° to 360°
2. **Multi-Curve Configuration**: 30°, 45°, 60° curves on single stencil
3. **Segment Numbering**: Discrete angular position markers
4. **Extrema Indicators**: High, low, and centerline markers
5. **Material**: Laser-cuttable acrylic or metal
6. **Scalability**: Software-generated for any diameter/angle

### Software Generation Pipeline
```
INPUT: Pipe diameter, branch angle
  ↓
COMPUTE: Discrete points via trigonometric projection
  ↓
INTERPOLATE: Smooth curve through points
  ↓
OUTPUT: Vector file (SVG/DXF) for laser cutting
```
