# FlameLang Usage Guide

## Installation

```bash
cd flamelang_compiler
cargo build --release
```

The compiler will be available at `target/release/flamec`.

## Basic Compilation

### Compile a Program
```bash
flamec examples/hello.flame
```

This produces:
- `examples/hello.rs` - Generated Rust source
- `examples/hello` - Native executable

### Compile and Run
```bash
flamec examples/hello.flame --run
```

### View FlameIR Only
```bash
flamec examples/hello.flame --ir-only
```

Output:
```json
{
  "instructions": [
    {"LoadString": "Hello, FlameLang!"},
    "Print",
    {"LoadConst": 42},
    ...
  ]
}
```

### Disable TRIG6 Optimizations
```bash
flamec examples/hello.flame --no-trig6
```

## Language Syntax

### Variables
```flame
let x = 42;
let name = "FlameLang";
```

### Arithmetic
```flame
let a = 10;
let b = 5;
let sum = a + b;
let product = a * b;
let diff = a - b;
let quotient = a / b;
```

Order of operations follows standard precedence:
- `*` and `/` before `+` and `-`
- Use parentheses for explicit grouping (future feature)

### Printing
```flame
print("Hello!");
print(42);
print(x + y);
```

### TRIG6 Functions
```flame
let angle = sin(90.0);   // Returns ~1
let phase = cos(0.0);    // Returns 1
let slope = tan(45.0);   // Returns ~1
```

Angles are in degrees (converted to radians internally).

### Comments (Future)
```flame
// This is a comment
let x = 42;  // Inline comment
```

Note: Comment support coming soon. For now, keep flame files comment-free.

## Example Programs

### Hello World
```flame
print("Hello, FlameLang!");
```

### Arithmetic
```flame
let x = 42;
let y = x + 8;
print(y);
```

### Bonding Rules Demo
```flame
// Demonstrates: state + transform → state'
let state_a = 10;
let state_b = 20;
let compound = state_a + state_b;  // state + state → compound_state
print(compound);

let transform_mul = compound * 2;  // state + transform → state'
print(transform_mul);
```

### Fibonacci (Limited)
```flame
let a = 0;
let b = 1;
print(a);
print(b);
let temp = a + b;
print(temp);
```

Note: Full iteration requires loops (future feature).

## Understanding the Output

### Birth Certificate
Every successful compilation generates a birth certificate:

```
🎉 BIRTH CERTIFICATE 🎉
═══════════════════════════════════════
Source:     examples/hello.flame
FlameIR:    11 instructions
Output:     examples/hello
TRIG6:      enabled
Timestamp:  2026-01-30 17:18:29
═══════════════════════════════════════
First successful FlameLang compilation!
```

### Generated Rust Code
The `.rs` file shows the stack-based execution:

```rust
// Generated by FlameLang Compiler
// KHAOS Script → FlameIR → Rust

use std::collections::HashMap;

fn main() {
    let mut stack: Vec<i64> = Vec::new();
    let mut vars: HashMap<String, i64> = HashMap::new();
    
    // Instruction 0: LoadString("Hello, FlameLang!")
    println!("Hello, FlameLang!");
    // Instruction 1: Print
    if let Some(val) = stack.pop() {
        println!("{}", val);
    }
    // ...
}
```

## Troubleshooting

### Error: "Parse error"
Check your syntax:
- Every statement must end with `;`
- Strings must be in double quotes
- Variable names must start with a letter

### Error: "rustc compilation failed"
The generated Rust code has an issue. This is a compiler bug.
Please report it with your `.flame` file.

### Error: "Error reading file"
Check that:
- File path is correct
- File exists and is readable
- File has `.flame` extension

## Advanced Usage

### Build with Debug Symbols
```bash
cargo build  # No --release flag
./target/debug/flamec examples/hello.flame
```

### Run Tests
```bash

```

### Benchmark Compilation Speed
```bash

```

### Check Generated IR
```bash
flamec examples/hello.flame --ir-only | jq .
```
