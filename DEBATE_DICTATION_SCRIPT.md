**Examiner:** "How do you calculate cos θ when agent objectives are not naturally expressed as geometric vectors?"

**Dom:**

"Great technical question. Each agent's objective is represented as a vector in an n-dimensional feature space. For example:

- Agent A working on 'cybersecurity threat detection' might have vector [0.9, 0.3, 0.1] representing {security_priority, speed_priority, cost_priority}
- Agent B working on 'system optimization' might have vector [0.2, 0.8, 0.5]

The cosine similarity between these vectors is:

```
cos θ = (A · B) / (||A|| × ||B||)
      = (0.9×0.2 + 0.3×0.8 + 0.1×0.5) / (√(0.9²+0.3²+0.1²) × √(0.2²+0.8²+0.5²))
      = 0.47 / (0.95 × 0.94)
      ≈ 0.53
```

This 0.53 value falls in the 'drift' range, indicating these agents are somewhat aligned but not strongly collaborating. The system would flag this for potential realignment.

The specification includes complete Python implementations demonstrating this calculation for realistic multi-agent scenarios."
