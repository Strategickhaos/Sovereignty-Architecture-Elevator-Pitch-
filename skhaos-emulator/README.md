## UDAP URI Schema

The Universal Domain Addressing Protocol (UDAP) provides everything-addressable URIs:

```
skhaos://bio/zipf/unit/1?law=entropy&hz=20
skhaos://bio/dolphin/whistle?signature=true&hz=10
skhaos://bio/dolphin/click?burst=200&hz=120
skhaos://physics/rondo/law=conservation&hz=10
skhaos://physics/fugue/law=relativity&hz=28
```

### Query Parameters
- `?zipf` - Zipf rank (1 = highest frequency)
- `?signature` - Dolphin signature ID flag
- `?law` - Physics law (entropy, uncertainty, conservation, relativity)
- `?hz` - Frequency in Hertz
- `?pod` - Dolphin pod identifier
- `?burst` - Echolocation burst count
- `?brevity` - Menzerath brevity flag
