### Template Type Clarification

**This tool generates branch-end templates** (wrap around branch pipe).

The template is used to:
1. Wrap around the branch pipe circumference
2. Mark the saddle curve cut line
3. Create perfect wye intersection geometry

Note: This does NOT generate main pipe opening (fishmouth) templates.
