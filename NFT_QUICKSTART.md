### 3. Deploy Steps

1. **Upload images to IPFS** (Pinata, NFT.Storage, or Infura)
2. **Update metadata** with real IPFS CIDs (replace `REPLACE_WITH_CID`)
3. **Deploy smart contract** using Hardhat or Remix IDE
4. **Mint tokens** using provided scripts
5. **List on marketplaces** (OpenSea, Rarible, Foundation)

✅ **7% Royalty** - Automatic on EIP-2981 compatible marketplaces
