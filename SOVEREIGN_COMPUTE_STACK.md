### LAYER 1: HARDWARE (SAGCO-DUINO CPU)

**Implementation:** Verilog HDL

**Specifications:**
- **Architecture:** 32-bit RISC
- **Registers:** 32 general-purpose registers
- **Program Counter:** 16-bit PC
- **Stack Pointer:** 11-bit SP
- **Pipeline:** 4-stage (FETCH → DECODE → EXECUTE → WRITEBACK)

**Instruction Set:**
```verilog
NOP   — No operation
MOV   — Move data between registers
LDI   — Load immediate value
ADD   — Addition
SUB   — Subtraction
AND   — Bitwise AND
OR    — Bitwise OR
XOR   — Bitwise XOR
JMP   — Unconditional jump
JZ    — Jump if zero
CALL  — Function call
RET   — Return from function
PUSH  — Push to stack
POP   — Pop from stack
```

**FPGA Targets:**
- Lattice iCE40 series
- Sipeed Tang Nano 9K/20K
- Other compatible FPGA platforms

**Files:**

**Q: Where's the CPU Verilog code?**  
A: It's archived in the zip files (`sagco-os-v0.1.0.zip` and related archives). Extract them to access `sagco_cpu.v`.

**Q: Can this run on real hardware?**
