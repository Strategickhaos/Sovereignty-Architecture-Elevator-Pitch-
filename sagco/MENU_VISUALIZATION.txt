                      DIRECTORY STRUCTURE
                      ===================

    /opt/sagco/
    ├── spm.yml                    ← Configuration
    └── bin/
        ├── sagco-menu.py          ← Python backend
        └── sagco-menu.sh          ← Bash frontend

    /etc/profile.d/
    └── sagco-menu.sh              ← Auto-launcher

    /var/lib/sagco/
    └── menu_state.json            ← State persistence


                         KEY COMMANDS
                         ============

    Launch Menu:
    $ /opt/sagco/bin/sagco-menu.sh

    List Categories:
    $ /opt/sagco/bin/sagco-menu.py categories

    Search Tools:
    $ /opt/sagco/bin/sagco-menu.py items all docker

    View Recent:
    $ /opt/sagco/bin/sagco-menu.py recent

    Add to Recent:
    $ /opt/sagco/bin/sagco-menu.py add_recent core-tools Git
