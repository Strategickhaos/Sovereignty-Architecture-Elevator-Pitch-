# TRIG6-Pruned IDA* Solver Solution

## Overview

This document describes the solution generated by the TRIG6-pruned IDA* solver algorithm for a cube-solving problem.

## Solution Details

- **Solver Algorithm**: TRIG6-pruned IDA*
- **Total Moves**: 7
- **Solution Sequence**: D2 R2 R L' U' D D2

## Algorithm Parameters

### Theta Gate Formula
```
θ = depth * π/32 + move_idx * π/18
```

This formula calculates the angle (theta) for each move based on:
- `depth`: Current search depth (0-6)
- `move_idx`: Index of the move in the move space

### Pruning Rule
```
abs(tan) > 10 OR norm² > 50
```

The algorithm prunes search branches when either:
- The absolute value of the tangent exceeds 10
- The squared norm exceeds 50

All steps in this solution passed the pruning criteria (pruned: false).

## Solution Steps

Each step includes:

1. **Geometric Properties**
   - `theta_rad`: Angle in radians
   - `theta_deg`: Angle in degrees
   - `sin_val`: Sine of theta
   - `cos_val`: Cosine of theta
   - `tan_val`: Tangent of theta
   - `norm_sq`: Squared norm of the state vector

2. **Move Information**
   - `move`: The cube move notation (e.g., D2, R2, L')
   - `move_idx`: Index in the move space
   - `depth`: Search depth when this move was found

3. **MIDI Mapping**
   - `midi_root`: Root MIDI note number
   - `midi_chord`: Array of MIDI notes forming a chord
   - `velocity`: MIDI velocity (volume/intensity)
   - `chord_type`: Major or minor chord classification

## Move Notation

Standard cube move notation is used:
- `U`: Up face clockwise
- `D`: Down face clockwise
- `R`: Right face clockwise
- `L`: Left face clockwise
- `'`: Counter-clockwise (e.g., L')
- `2`: 180-degree turn (e.g., D2)

## Usage

To access the solution data:

```bash
# View the entire solution
cat trig6_solver_solution.json

# Extract just the solution sequence
jq '.solution' trig6_solver_solution.json

# View metadata
jq '.metadata' trig6_solver_solution.json

# View a specific step
jq '.steps[0]' trig6_solver_solution.json
```
