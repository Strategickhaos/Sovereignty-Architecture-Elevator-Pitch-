## Customization Instructions

### Step 1: Choose Template
Select the footer template that matches your document type.

### Step 2: Fill Placeholders
Replace all `{placeholders}` with actual information:
- `{Your Name}` → Your actual name
- `{System Name}` → Specific system(s) used
- `{Date}` → Current date
- `{UNIQUE_ID}` → Document tracking ID
- etc.

### Step 3: List Relevant Systems
Only include systems you actually used:
```
Used FlameLang only? → List only FlameLang
Used TRIG6 and SAGCO-OS? → List both
Used all systems? → List all
```

### Step 4: Adjust Length
- Space available? → Use full footer
- Space limited? → Use minimal footer
- Code file? → Use comment footer

### Step 5: Maintain Consistency
Use the same footer style across all documents in a project.

## Legal Considerations

### These Footers Provide:
✅ Clear copyright notice  
✅ License specification  
✅ IP ownership statement  
✅ AI usage transparency  
✅ Organizational attribution  
✅ Verification references  

### These Footers Do NOT:
❌ Replace proper citation of external sources  
❌ Override institutional requirements  
❌ Constitute legal advice  
❌ Guarantee acceptance by all evaluators  

### Always Remember:
- Footers supplement, not replace, proper attribution
- Follow all institutional and assignment guidelines
- Be honest and transparent about methodology
- Maintain academic integrity through disclosure
